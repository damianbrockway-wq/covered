# Covered

A fully-offline homeschool **year-end report** app. One self-contained HTML file —
no server, no accounts, no internet. Data is stored locally in the browser.
Generates an evaluator-ready **Word (.docx)** and **PDF** with one click.

Built for Maine defaults (175 days, 10 required subjects); editable for any state.

## Run locally
Just open `public/index.html` in any browser.

## Deploy (Cloudflare Pages)
```
wrangler pages deploy
```

Not legal advice — homeschool requirements vary by state; confirm with your school
administrative unit.
